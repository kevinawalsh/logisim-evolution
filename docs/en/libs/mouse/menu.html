Menu Tool

Found in Mouse Tools

Menu Tool gets activated when right-clicking within the circuit, or left-clicking with Control held. This brings up a context-sensitive pop-up menu with actions relevent to whatever was clicked.

By default, the Move Tool is not visible in the toolbar, because it usually gets invoked by right-click or control-click. You can add it to project's toolbar by right-clicking the toolbar, or change the mouse-click behavior by going to Project > Options then Mouse Options.

The contents of the pop-up menu depends on what was clicked.

  • Most components show cut, copy, paste, delete, rotate, and similar actions.

  • Subcircuit components have "View Inner Simulation..." and "View Circuit Design..." options. Both of these show the inner circuit represented by the component, they differ only in how the inner circuit's simulation is configured.

    • For "View Inner Simulation...", the inner circuit's simulation works like a window into the outer circuit's current state. You can probe wires, or even edit the circuit. But you can't change the value of the inner circuit's input pins, because those are tied to, and determined by, the outer circuit.

    • For "View Circuit Design...", the inner circuit's simulation is a new, independent simulation. You can probe wires, or change the value of input pins, without having any affect on other simulations.
