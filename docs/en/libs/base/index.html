Mouse Tool Library

The Mouse Tool Library includes tools for editing and interacting with circuits. This library is not shown in the left navigation panel, it is only visible when you right-click the toolbar and select "Customize...", as these tools normally only appear in the toolbar.

Poke Tool — interact with running simulation
Multi-Tool — select and move components, or draw and edit wires
Wiring Tool — draw and edit wires only
Wire Cutter — delete wires or cut portions of wires
Text Tool — add or edit comment boxes, labels on components, and other text
The Move and Popup tools are less useful so aren't included in the toolbar by default. You can customize the toolbar to add them.
Move Tool— select and move components only
Popup Menu Tool — bring up the right-click context menu
