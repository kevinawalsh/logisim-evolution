Text (Plain) — places a plain-text label on the canvas.

The label uses a single font and has no line wrapping. Use it for short annotations, signal names, or component labels.

  • Text — the content of the label (double-click to edit in place)
  • Font — typeface, style, and size
  • Horizontal Align — left, center, or right relative to the anchor point
  • Vertical Align — top, center, or bottom relative to the anchor point
