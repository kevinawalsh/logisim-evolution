LED Bar

A row of LEDs displaying bit values.

See also: Reference, demo

Shortcuts

Arrow keys

rotate

Alt or Option + Arrow keys

move label

Type a number

change number of segments

Properties

Facing

Direction the bar extends.

Input Format

Separated (one port per LED) or bus (one multi-bit port).

Segments

Number of LEDs.

Active on High?

Whether 1 or 0 lights each LED.

On/Off Colors

Colors for lit and unlit LEDs.

LED Shape

Square or circle LEDs.

Label/Location/Font/Color

Label attached to LED Bar.
