Move Tool

Select and move components and wires.

See also: Reference

Selecting and Moving Stuff

Click something

select it

Click-drag the background

select area

Shift + click something

add or remove it from selection

Shift + Click-drag the background

add area to selection

Click-drag selected things

move them & tries to preserve connections

Shift + Click-drag selected things

move, don't preserve connections, and always snap to grid

Shortcuts

Backspace/Delete

delete selected things

Up/Down/Left/Right

rotate selected things, if possible

Insert

duplicate selected things
