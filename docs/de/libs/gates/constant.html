Aussehen:

Verhalten

Emits the value specified in its Value property.

Pins

There is only one pin, an output whose bit width matches the Data Bits property. The location of this pin is specified in the Facing property. The component constantly outputs on this pin whatever value specified in the Value property.

Property

When the component is selected or being added, the hexademical digits '0' through '9' and 'a' through 'f' alter its Value property, Alt-0 through Alt-9 alter its Data Bits property, and the arrow keys alter its Facing property.

Ausrichtung
The direction in which the pin is located relative to where the value is drawn.
Data Bits
The bit width of the component's inputs and outputs.
Value
The value, written in hexademical, that is emitted by the component. The number of bits used to specify the value cannot exceed the component's bit width.
