Poke Tool

Found in Mouse Tools

Behavior

The Poke Tool is for interacting with a circuit: use the mouse and keyboard to probe values, change inputs, edit values stored in registers and memory, and prod other components to change state or perform actions.

Live Circuit: Interaction using input and poke tool

Many components respond to being poked:

  • Poke a wire or bus to see the value it carries. For a bus, poke again to see the value in hex, signed decimal, and other encodings.
  • Poke a Button, DipSwitch, or Joystick to change it's value.
  • Poke a binary Input Pin to toggle its value, or poke a decimal or hex input pin then type enter new values.
  • Poke a Register, Counter, or other memory component then type to modify the values stored within.
  • Poke a Clock, repeatedly, to make it tick.
  • Poke an Embedded Subcircuit (double-click the magnifying glass that appears) to open and inspect its internal circuit.
  • Poke a Hyperlink component, or links in styled text block comments to open the URL in a browser.
Hint: When poking a bus wire, you can configure which encodings are shown first — binary, signed decimal, unsigned decimal, octal, hexadecimal — by going to Layout preferences.

For some pokable components, like multi-bit Registers, hex or multi-bit Input Pins, the mouse and keyboard must be used in combination: poke the component to select it, then type to enter hex or other data.

Easy Keyboard Hotkeys

Poking things with the mouse can be tiresome, especially for circuits with several inputs or buttons. You can enable easy keyboard interaction in your circuits: just label any component with a one-letter name. Then, when using the poke tool, typing the letter will poke that named component, just as if you had clicked it. This only works if you haven't already selected some component that expects keyboard input.

You can even name several components with the same hotkey, typing it will poke them all. This kind of keyboard interaction is most useful with buttons and one-bit input pins.
