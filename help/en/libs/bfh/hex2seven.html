Hex2SevenSegment

Library: BFH mega functions
Introduced: 3.x.x
Appearance:

Behavior

This component converts a four-bit hex digit to a format suitable for use with a 7-Segment Display. The Hex2SevenSegment component as a "hole" in the center, sized to exactly fit one such display.

This component is not necessary in most scenarios—it was created as a stop-gap measure before FPGA support was added to many components, but is no longer useful for new circuits. Rather than using a Hex2SevenSegment converter paired with a Seven Segment Display, you can simply use a Hex Digit Display alone (which internally contains identical number format conversion logic).

Pins

South edge (input, four bits)
The hex digit to be converted.
Inside edges (seven outputs, one bit each)
Outputs corresponding to the seven inputs of a 7-Segment Display.

Properties

None.

Note: A number of properties are defined for this component, but none are useful in any way. They should all be ignored.

Poke Tool Behavior

None.

FPGA Synthesis

Supports VHDL synthesis.
