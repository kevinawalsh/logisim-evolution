Edit Tool — move, select, and rearrange components and wires.

See also: Reference

Drawing Wires:

  • Click-drag a port → draw a wire from the port
  • Click-drag a wire → change wires or draw new wires
  • Alt or Option + click-drag a wire → move a wire segment
  • Alt or Option + click-drag background → draw new wires
  • Space while drawing a wire → add a corner point
  • Backspace/delete while drawing a wire → remove a corner point

Selecting and Moving Stuff:

  • Click something → select it
  • Click-drag the background → select area
  • Shift + click something → add or remove it from selection
  • Shift + Click-drag the background → add area to selection
  • Click-drag selected things → move them & tries to preserve connections
  • Shift + Click-drag selected things → move, don't preserve connections, and always snap to grid

Shortcuts:

  • Backspace/Delete → delete selected things
  • Up/Down/Left/Right → rotate selected things, if possible
  • Insert → duplicate selected things
