Poke Tool — Interact with circuit using mouse and keyboard.

Click...
  • Any key → poke all components with that label
  • a wire → show value it carries. Repeat or hit space to see more.
  • a clock → make it tick
  • a button → change its value
  • one-bit input pin → change its value
  • multi-bit input pin, then type → change its value
  • one-bit register → change its state
  • multi-bit register, then type → change its state
  • subcircuit (double-click on the spyglass) → view inner simulation of that circuit
